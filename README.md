# ليلة فالخيمة

موقع لعبة اجتماعية مغربية واحدة: **ليلة فالخيمة — الفقيه والمسكون**. تجربة Mobile-first قابلة للتثبيت كتجمع الأصدقاء فغرف عامة وخاصة، مع دردشة وصوت مباشر وأدوار سرية.

## التقنية
- React 18 + TypeScript + Vite.
- Supabase Auth + PostgreSQL + RLS + Realtime.
- Cloudflare Pages وPWA.
- WebRTC للصوت المباشر داخل الغرف.

## تجربة اللعب
- لعبة واحدة فقط فالموقع: ليلة فالخيمة.
- من 4 حتى 10 لاعبين.
- أدوار سرية: المسكون، الفقيه، والمواطنون.
- مراحل الليل والصباح والنهار والتصويت.
- حماية اللاعب، إعلان النجاة أو الموت، وإعادة التصويت عند التعادل.
- الفوز للمواطنين بطرد المسكون، وللمسكون ملي يبقا مواطن واحد أو أقل.
- دردشة الغرفة والصوت المباشر اختيارياً.

## وظائف المنصة المساندة
- تسجيل الدخول وإنشاء الحساب واسترجاع كلمة السر.
- إنشاء غرف عامة وخاصة والانضمام بكود.
- لائحة الغرف العامة، دعوة الأصدقاء، والدردشة الخاصة.
- بروفايل اللاعب، النقاط، XP، العملات، الإنجازات ولوحة المتصدرين.
- مهمات يومية ومكافأة يومية ومتجر العناصر التجميلية.
- PWA قابلة للتثبيت على الهاتف.

## قاعدة البيانات
المigrations موجودة داخل `database/` ومرتبة حسب أرقامها. لا تفتح schema `private` للـData API، ولا تضع service-role أو TURN secrets في الواجهة أو GitHub.

## إعداد الواجهة
1. انسخ `.env.example` إلى `.env`.
2. ضع `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY`.
3. فعّل Email Auth واضبط SMTP لتأكيد البريد.
4. اضبط Site URL وRedirect URLs على رابط Cloudflare Pages.
5. شغّل `npm install` ثم `npm run dev`.

## الصوت
WebRTC mesh مناسب للمجموعات الصغيرة. STUN وحده لا يضمن الاتصال عبر جميع أنواع NAT؛ يلزم إعداد TURN داخل Worker عند الحاجة، مع عدم وضع أسراره في الواجهة.

## الفقيه والمسكون — تفاصيل التشغيل والأمان
- Migration `033_haunted_camp_game.sql` كتضيف محرك الأدوار السرية والتصويت والنتائج بسياسات RLS وRPC.
- Migration `034_haunted_camp_completion.sql` كتضيف Feature Flag فـ `games_catalog`، وكتخلي الغرفة ترجع للّوبي بعد نهاية اللعبة، وكتضيف مكافآت Gems وربح أول مرة فالنهار.
- تفعيل/تعطيل اللعبة كيتدار من `public.games_catalog` بتغيير `is_enabled`؛ الكتابة محصورة فـ JWT ديال الإدارة.
- اختيارات الليل محفوظة فـ `haunted_night_actions` وما عندهاش سياسات قراءة للعميل. الأدوار ما كيبانوش حتى تسالي اللعبة.
- الأصوات الحالية مولّدة بـ Web Audio API باش تخدم بلا ملفات خارجية؛ ملفات MP3 اختيارية ويمكن إضافتها لاحقاً داخل `frontend/public/sounds/`.
- Design tokens فـ `frontend/src/styles/tokens.css` و`tokens.ts`. كاين احترام لإعداد `prefers-reduced-motion` وأزرار اللعبة عندها حد أدنى 48px.
- CI كيشغل الاختبارات، TypeScript/Vite build، و`npm audit --audit-level=high`.

**ملاحظة:** الصوت والصورة والـRealtime خاصهم اختبار يدوي بحسابات مستقلة؛ CI ما كيقدرش يعوض اختبار 4–10 لاعبين أو فحص WebRTC عبر شبكات مختلفة.


## تحسين صوت وأنيميشن «ليلة فالخيمة»
- `audioManager.ts` كيشغّل MP3 محلية من `public/sounds` مع fade-in/fade-out للمؤثرات المحيطية، وWeb Audio fallback إلا الملف مازال ما توفرش.
- `hauntedAudio.ts` كيربط أصوات الليل والصباح والقتل والحماية والتصويت والطرد والنهاية.
- preload كيتدار ملي كتفتح اللعبة، وService Worker v13 كيخزّن ملفات الصوت اللي كتتحمّل باش تبقى متاحة Offline.
- Framer Motion كيتحكم فـ flip ديال الدور، انتقالات الليل والصباح، وهزة الموت وglow النجاة وconfetti الفوز؛ `useReducedMotion` كيعطّل الحركة الثقيلة.
- PWA manifest تحدّث بالهوية اللونية الجديدة، وcache version تزاد باش يتفرض تحديث Service Worker.
- ملفات MP3 الأصلية خاصها تضاف بأسماء الملفات الموجودة فـ `frontend/public/sounds/README.md`، مع توثيق المصدر والرخصة فـ `ATTRIBUTION.md`. ما ضفتش ملفات صامتة أو مزيفة.
